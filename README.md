🚌 PSRU Shuttle App

โปรเจกต์แอปพลิเคชันสำหรับติดตามและเรียกรถรับส่งภายในมหาวิทยาลัย (PSRU) พัฒนาด้วย Flutter และใช้ระบบฐานข้อมูลแบบ Real-time ด้วย Firebase

แอปพลิเคชันนี้ถูกออกแบบมาเพื่ออำนวยความสะดวกให้นักศึกษาสามารถดูตำแหน่งรถรับส่ง, ทราบเส้นทางเดินรถ, ส่งสัญญาณแจ้งรอรถที่ป้าย, และสามารถแชทพูดคุยกับคนขับรถได้แบบเรียลไทม์

✨ ฟีเจอร์หลัก (Key Features)

🗺️ แผนที่และการนำทาง (Map & Routing)

แสดงแผนที่มหาวิทยาลัยด้วย flutter_map (OpenStreetMap)

แสดงหมุดจุดจอดรถ (Bus Stops) และตำแหน่งรถบัส

ระบบ Highlight Route อัลกอริทึมคำนวณและวาดเส้นทางจากรถบัสไปยังจุดจอดที่นักศึกษาเลือกได้อย่างแม่นยำ

👥 ระบบสิทธิ์ผู้ใช้งาน (Role-based System)

รองรับการสมัครสมาชิกและเข้าสู่ระบบ 2 รูปแบบ: นักศึกษา (Student) และ คนขับรถ (Driver)

👋 ระบบเรียกรถรับส่ง (Ride Request)

นักศึกษาสามารถกด "แจ้งรอรถที่จุดนี้" ข้อมูลจะส่งตรงไปยังคนขับ

เมื่อคนขับกดรับทราบ สถานะในแอปนักศึกษาจะเปลี่ยนพร้อมแจ้งเตือนทันที

💬 ระบบแชทเรียลไทม์ (Real-time Chat)

พูดคุยสอบถามสถานะกับคนขับรถได้ทันทีผ่าน Firebase Cloud Firestore

⭐ จุดจอดโปรด (Favorite Stops)

บันทึกป้ายรถเมล์ที่ใช้บ่อย เพื่อให้แสดงขึ้นมาเป็นอันดับแรกในช่องค้นหา

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

Frontend: Flutter (Dart)

Backend: Firebase (Authentication, Cloud Firestore)

Packages สำคัญ:

flutter_map: สำหรับจัดการแผนที่

latlong2: สำหรับจัดการพิกัด GPS

intl: สำหรับจัดการฟอร์แมตเวลาในการแชท

🚀 การเริ่มต้นใช้งาน (Getting Started)

คำแนะนำเบื้องต้นสำหรับการรันโปรเจกต์นี้บนเครื่องของคุณ:

สิ่งที่ต้องมี (Prerequisites)

ติดตั้ง Flutter SDK บนเครื่องคอมพิวเตอร์

บัญชี Firebase สำหรับเชื่อมต่อฐานข้อมูล (โปรเจกต์นี้รองรับ Web, Android, iOS)

วิธีการรันแอปพลิเคชัน

ติดตั้งแพ็กเกจที่จำเป็นทั้งหมด เปิด Terminal แล้วพิมพ์คำสั่ง:

flutter pub get


รันแอปพลิเคชันบน Emulator หรือ อุปกรณ์จริง:

flutter run


(หากต้องการทดสอบฝั่งคนขับ แนะนำให้รันบน Chrome Web ด้วยคำสั่ง flutter run -d chrome เพื่อจำลองพิกัด GPS จำลองได้ง่าย)

### 📱 วิธีการทดสอบแอปบน iPhone (สำหรับผู้พัฒนาบน Windows Laptop)

เนื่องจากระบบปฏิบัติการ Windows ไม่สามารถคอมไพล์ไฟล์ iOS Native (.ipa) โดยตรงได้เนื่องจากข้อจำกัดของ Apple (ต้องใช้ Xcode บน macOS) แต่คุณสามารถทดสอบการใช้งานบน iPhone ได้ด้วย 3 วิธีหลักดังนี้:

#### 1. ทดสอบผ่าน Flutter Web บน Local Network (แนะนำ - ง่ายและเร็วที่สุด ⭐)
วิธีนี้ไม่ต้องติดตั้งไฟล์แอปจริงลงเครื่อง แต่สามารถเปิดใช้งานและทดสอบ UI/UX บนหน้าจอ iPhone ผ่านเบราว์เซอร์ได้ทันที:
1. เชื่อมต่อ Windows Laptop และ iPhone ให้อยู่ใน **เครือข่าย Wi-Fi เดียวกัน**
2. หา IP Address ของคอมพิวเตอร์ (เปิด Command Prompt พิมพ์ `ipconfig` ดูที่ `IPv4 Address` เช่น `192.168.1.45`)
3. รัน Flutter ในโหมด Web Server ให้รับการเชื่อมต่อจากอุปกรณ์อื่นในวงแลน:
   ```bash
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
   ```
4. เปิด **Safari** บน iPhone แล้วพิมพ์ URL: `http://<IP-Address-ของคอมพิวเตอร์>:8080` (เช่น `http://192.168.1.45:8080`)
5. *💡 เคล็ดลับเพิ่มเติม:* กดปุ่ม **Share (แชร์)** ใน Safari แล้วเลือก **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อจำลองการเปิดแอปแบบเต็มจอเสมือนติดตั้งแอปจริง

#### 2. ใช้บริการ Cloud CI/CD (เช่น Codemagic หรือ GitHub Actions)
หากต้องการคอมไพล์ไฟล์ไปติดตั้งเป็นแอป Native บน iPhone จริงๆ:
1. อัปโหลดโปรเจกต์ขึ้น GitHub Repository
2. สมัครใช้งาน **Codemagic** (ระบบ CI/CD ยอดนิยมสำหรับ Flutter ที่มี Cloud macOS ให้ใช้ฟรีสำหรับโปรเจกต์ทั่วไป)
3. ตั้งค่า Workflow ให้คอมไพล์โค้ดฝั่ง iOS ออกมา
4. นำไฟล์ที่ Build เสร็จไปทดสอบผ่านแอป **TestFlight** (ต้องมี Apple Developer Account) หรือส่งลิงก์ติดตั้งแบบ Ad-hoc ลง iPhone

#### 3. ยืมหรือใช้งานผ่านเครื่อง macOS / Cloud Mac
หากต้องการ Build และ Debug แบบเสียบสายตรงกับเครื่อง:
- โอนย้ายโค้ดโปรเจกต์ไปรันบนเครื่อง Mac (เช่น ยืมเครื่องในทีมหรือกลุ่มเพื่อน) แล้วเปิดไฟล์ `ios/Runner.xcworkspace` ด้วยโปรแกรม **Xcode** เพื่อรันลง iPhone
- หรือใช้บริการเช่าเครื่อง Mac บนคลาวด์ เช่น **MacinCloud** หรือ **AWS EC2 Mac instance**
