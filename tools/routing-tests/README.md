# ทดสอบเส้นทางข้ามป้าย 5

จากโฟลเดอร์โปรเจกต์:

```powershell
flutter test test/stop_five_bypass_test.dart
node tools/routing-tests/replay.mjs
```

หาก Dart ไม่ได้อยู่ที่ `C:/src/flutter/bin/cache/dart-sdk/bin/dart.exe`
ให้ตั้ง environment variable `DART_EXE` เป็นตำแหน่ง Dart SDK ก่อนรัน replay
ต้องติดตั้ง dependencies ของแอปไว้แล้ว

Unit tests ตรวจการเลือกแขนงถนน การยืนยันด้วยตำแหน่งที่เคลื่อนไปข้างหน้า
GPS แกว่ง การแยกสถานะรถ และการล้างสถานะเมื่อพ้นช่วงป้าย 4

Replay ดึงบล็อกสร้าง graph และเลือก waypoint จาก `student_home.dart`
โดยตรง ใช้ `route_data.dart` จริง และพิกัดป้าย 4/5/6 ที่ตรวจสอบจาก Firestore
แบบอ่านอย่างเดียวเมื่อ 2026-09-09 ไม่ต่อ Firebase ระหว่างทดสอบ
มี fixture ป้าย 7 สำหรับตรวจว่าป้ายถัดไปไม่ถูกตัดออก
ไฟล์ Dart ชั่วคราวจะถูกลบหลังจบการทดสอบ

เกณฑ์ปัจจุบัน: รถพ้นจุดแยกบนแนวไปป้าย 6 อย่างน้อย 25 เมตร
ห่างแนวถนนไม่เกิน 18 เมตร และใกล้แนวนี้กว่าทางเข้าป้าย 5 อย่างน้อย
15 เมตร จากนั้นต้องเห็นตำแหน่งใหม่เดินหน้าอีกอย่างน้อย 5 เมตร
ตำแหน่งซ้ำจาก heartbeat ไม่ทำให้ยืนยันการข้าม
ใช้เกณฑ์นี้เฉพาะเมื่อ `last_passed_stop` เป็น 4 และแยกทางเลือกได้จาก graph
หากป้ายหาย พิกัดห่าง node เกิน 25 เมตร หรือไม่มีทางเลือก จะใช้ระบบเดิม

ควรทดสอบขับรถจริงทั้งเที่ยวแวะและไม่แวะป้าย 5 เพื่อปรับเกณฑ์ตาม GPS
ผลทดสอบอัตโนมัติไม่ใช่การยืนยันความแม่นยำของ GPS บนถนนจริง
